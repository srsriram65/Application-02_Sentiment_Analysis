# Application 2 - Sentiment Analysis

## Aim
To classify a given text as Positive, Negative, or Neutral.

## Description
This application uses a simple rule-based approach to identify sentiment from text.

## Input
I love this application. It is amazing.

## Output
Sentiment: Positive

## Technologies Used
- Python
- Google Colab

## Application
This program can be used to identify the basic emotional sentiment of text.
